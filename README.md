# IconDash

浏览器新标签页图标仪表盘 —— 打开新标签页，展示你收藏的网站图标，点击一键跳转。

## 功能

- **图标网格** — 响应式网格布局，自适应屏幕宽度
- **可视化编辑** — 添加、编辑、删除链接，右键菜单操作
- **收藏夹导入** — 一键从浏览器收藏夹批量导入链接，自动去重
- **自动获取图标** — 通过 Google Favicon API 自动获取网站 favicon
- **搜索过滤** — 输入关键词实时过滤图标，输入网址直接跳转
- **玻璃拟态主题** — 深色主题 + 动态渐变光球背景 + 毛玻璃效果
- **时间显示** — 顶部显示当前时间和日期
- **键盘操作** — `Esc` 关闭弹窗，任意键聚焦搜索框，`Enter` 快速跳转

## 安装

1. 克隆仓库
   ```bash
   git clone https://github.com/hyz-zhao/IconDash.git
   ```

2. 打开 Chrome/Edge，地址栏输入 `chrome://extensions/`

3. 右上角开启**开发者模式**

4. 点击**加载已解压的扩展程序**，选择 `IconDash` 文件夹

5. 打开新标签页即可使用

## 使用

| 操作 | 方式 |
|------|------|
| 添加链接 | 点击 `+` 按钮，或搜索框为空时按 `Enter` |
| 编辑链接 | 右键图标 → 编辑 |
| 删除链接 | 右键图标 → 删除 |
| 导入收藏夹 | 点击搜索框下方「从收藏夹导入」按钮 |
| 搜索 | 在搜索框输入关键词 |
| 跳转 | 点击图标，或搜索匹配后按 `Enter` |

## 技术栈

- Manifest V3 浏览器扩展
- 原生 HTML / CSS / JavaScript
- `chrome.bookmarks` API 读取收藏夹
- localStorage 数据持久化
